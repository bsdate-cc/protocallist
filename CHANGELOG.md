# Журнал изменений

Номер версии — `protocallist.VERSION`. Новые версии сверху.

## 0.1.0 — 2026-10-13

Первая версия.

- **Запись.** Разговор замечается сам: программа заняла выбранный микрофон — началась запись, микрофон
  свободен пять секунд — запись окончена. Пишутся две стороны отдельно: микрофон и то, что слышно в
  наушниках. Записи короче пяти секунд выбрасываются. Пока запись не включена в меню, программа ничего
  не пишет.
- **Текст.** После разговора обе стороны распознаёт Толмач (0.8.0 или новее) на этом же компьютере;
  фразы со временем складываются в один разговор и хранятся в базе. Толмач не запущен — разговор ждёт.
  Вместо Толмача можно задать свой сервер, который принимает тот же запрос (`gateway.url`,
  `gateway.model`, `gateway.key_file`).
- **Архив.** Звук разговора — один стереофайл Opus, около 26 МБ за час: слева вы, справа собеседники.
  Он хранится 30 дней (настройка `storage.keep_audio_days`), текст и выжимки остаются насовсем.
- **Панель в браузере.** Список разговоров с поиском по сказанному и страница каждого из них: текст по
  репликам, проигрыватель для обеих сторон или для одной, выжимка. Панель открывается из значка и
  доступна только с этого компьютера и только по ключу.
- **Выжимка по щелчку.** Текст одного разговора отдаётся Claude Code или вашей собственной команде
  (`summary.command`), свои указания для выжимки — в файле (`summary.prompt`). Несколько отмеченных
  разговоров обрабатываются по очереди.
- **Распознать заново другой моделью** — например английской; нужен Толмач 0.10.0 или новее.
- **Значок в трее** с состоянием и меню, запуск вместе с Windows, два языка — русский и английский.
- **Запуск двойным щелчком** по `protocallist.cmd`: окружение Python, проверки, недостающие библиотеки.
- **Обновление через git, по щелчку:** когда в репозитории есть версия новее, в меню появляется
  «Обновить до X.Y.Z». Если код на диске изменился, меню предлагает перезапуск.
