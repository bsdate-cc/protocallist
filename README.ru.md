# Протоколист

Программа для Windows, которая записывает ваши звонки. Когда какая-нибудь программа на компьютере
занимает микрофон гарнитуры — Zoom, Telegram, браузер, корпоративный мессенджер, — Протоколист
записывает разговор: ваш голос и то, что слышите вы, двумя отдельными дорожками. После звонка он
превращает запись в текст с помощью [Толмача](https://github.com/bsdate-cc/tolmach) — сервиса
распознавания речи, который работает на вашем же компьютере, — и хранит текст, звук и, если
попросите, выжимку в архиве. Архив открывается в браузере: разговоры можно читать, слушать и искать
по ним.

Сказанное остаётся на вашем компьютере, пока вы сами не попросите выжимку: см.
[Что уходит с компьютера](#что-уходит-с-компьютера).

*Латиницей программа пишется Protocallist: слово «протоколист», записанное так, чтобы в нём читалось
call list — «список звонков».* Из коробки текст получается **русский** (основная модель Толмача);
разговор на **английском** можно распознать заново английской моделью Толмача. Меню значка и панель
есть на русском и английском.

**[Read in English](README.md)**

## Прежде чем кого-то записывать

В записи остаются голоса и слова других людей. Нужно ли их предупреждать, нужно ли спрашивать
согласия и можно ли записывать вообще — зависит от закона там, где живёте вы и они, и от правил
вашего работодателя. Программа этого за вас не решает и никого не предупреждает: запись ваша, и
ответственность тоже ваша. Запись **выключена**, пока вы сами её не включите.

## Что он умеет

- **Сам замечает звонок.** Разговор начинается, когда программа занимает выбранный вами микрофон, и
  заканчивается через пять секунд после того, как микрофон освободился. Кнопок нажимать не надо, и
  на экране ничего не появляется — уведомление вылезло бы на экран, который вы показываете.
- **Пишет две стороны отдельно:** микрофон и то, что звучит в наушниках той же гарнитуры. В архиве
  звук — один небольшой стереофайл (Opus, около 26 МБ за час): слева вы, справа собеседники.
- **Превращает звонок в текст**, когда он закончился, через Толмач на том же компьютере или через
  ваш собственный сервер: кто что сказал и когда, «Я» и «Собеседники». Пока идёт запись, ничего не
  распознаётся.
- **Панель в браузере:** список разговоров с поиском по сказанному и страница каждого из них —
  текст, проигрыватель для обеих сторон или для одной, выжимка.
- **Выжимка по щелчку:** текст этого одного разговора отдаётся
  [Claude Code](https://claude.com/claude-code) — или вашей собственной команде, — а выжимка
  хранится вместе с разговором. Можно отметить несколько разговоров и сделать выжимки по очереди.
- **Другая модель для другого языка:** пока хранится звук, разговор можно распознать заново любой
  моделью, которая есть в вашем Толмаче, — например английской.
- **Старый звук уходит, текст остаётся:** звук хранится 30 дней (это настройка), текст и выжимки —
  насовсем.
- **Значок в трее** показывает состояние: запись выключена, ждёт разговора, идёт запись, разговор
  превращается в текст, ошибка.
- **Обновления** через git: когда в репозитории появилась версия новее, в меню появляется пункт
  «Обновить до X.Y.Z». Само ничего не ставится.

## Как это устроено

Один процесс без окна держит значок в трее, следит за микрофоном, записывает, отправляет записи на
распознавание и отдаёт панель.

Раз в секунду он спрашивает у Windows, какие программы держат выбранный микрофон. Программы из
списка `recording.ignore` не считаются: по умолчанию это Python (под ним работают программы
диктовки, тот же Толмач) и звуковые настройки Windows. Обе стороны пишутся на диск по мере
поступления звука, поэтому оборванная запись — программу завершили, пропало питание — приводится
в порядок при следующем запуске.

Когда звонок закончился, каждая сторона режется в тихих местах на куски не длиннее десяти минут, и
куски уходят шлюзу Толмача на `127.0.0.1`. Вернувшиеся фразы, каждая со своим временем,
выстраиваются по общему времени разговора и сохраняются в базе SQLite; две записи после этого
становятся одним файлом Opus. Пока Толмач не запущен, разговор ждёт и распознаётся, когда Толмач
появится.

Панель — это страница, которую программа сама отдаёт на `127.0.0.1`, на порту вашей учётной записи
Windows (40701 для первой учётной записи компьютера). Открывается она из значка в трее: в ссылке
есть ключ, который лежит в вашей папке пользователя, и без ключа сервер ничего не показывает.
Запросы с других сайтов и с других портов этого компьютера отклоняются. Из сети страница ничего
не загружает.

## Что уходит с компьютера

- **Из ваших разговоров само — ничего.** Запись, распознавание и архив остаются на этом компьютере.
  В журнале — имена программ, время и ошибки; сказанного там нет никогда, заголовков окон тоже.
- **На свой сервер распознавания, если вы его задали, — звук каждого разговора.** Он уходит по
  адресу из `gateway.url` сам, как только звонок закончился. По `http://` ни звук, ни ключ не скрыты
  от того, кто стоит на пути: держите такой сервер на этом компьютере или в сети, которая ваша.
- **Выжимка — по вашему щелчку, для этого одного разговора.** Его текст уходит в Claude Code —
  команду `claude`, которую вы сами установили и в которой вошли в свою учётную запись, — а она
  отправляет его в Anthropic; либо команде, которую вы задали в `summary.command`. Claude
  запускается без инструментов и не сохраняет сеанс.
- **Проверка обновлений** спрашивает у GitHub состояние этого репозитория: при запуске программы,
  каждые шесть часов и когда вы выбираете этот пункт в меню. Ничего вашего в этом запросе нет.

## Что нужно

- Windows 10 или 11, 64 бита.
- [Python 3.12](https://www.python.org/downloads/) (64 бита) и [git](https://git-scm.com/).
- Гарнитура. Если микрофон не часть гарнитуры — веб-камера, микрофон на столе, — укажите в
  `recording.speaker` имя устройства, через которое вы слышите звонок, иначе запишется только ваша
  сторона.
- [Толмач](https://github.com/bsdate-cc/tolmach) 0.8.0 или новее, запущенный на том же компьютере, —
  для текста; либо ваш собственный сервер, который принимает тот же запрос, см. ниже «Свой сервис
  распознавания». Без того и другого звонки записываются и ждут: значок говорит, сколько их, и,
  пока они не распознаны, это обычный звук, около 230 МБ за час, который ничто не удаляет. Чтобы
  распознать разговор заново другой моделью, нужен Толмач 0.10.0 или новее.
- [Claude Code](https://claude.com/claude-code) — только для выжимок и только если вы не задали
  собственную команду.

## Установка

```
git clone https://github.com/bsdate-cc/protocallist.git
cd protocallist
.\protocallist.cmd
```

`protocallist.cmd` (можно и двойным щелчком по файлу) создаёт окружение `.venv` и проверяет Python,
библиотеки, папку данных и настройки; недостающие библиотеки предлагает поставить через pip. Потом
запускает программу без окна, и в трее появляется значок — Windows может спрятать его среди скрытых
значков, за стрелкой возле часов. Каждый шаг печатается в окне и пишется в `logs\startup.log`.

После первого запуска — в меню значка:

1. **Микрофон для разговоров** — выберите микрофон своей гарнитуры.
2. **Записывать разговоры** — включите.

Дальше звонки записываются сами.

## Как пользоваться

Меню значка в трее:

| Пункт | Что делает |
|---|---|
| **Открыть панель** | открывает архив в браузере; то же делает простой щелчок по значку |
| **Записывать разговоры** | включает и выключает запись |
| **Остановить и удалить эту запись** | виден, пока идёт запись, — для звонка, который записывать не стоило |
| **Микрофон для разговоров** | микрофоны этого компьютера; выбранный отмечен |
| **Открыть папку разговоров** | папка со звуковыми файлами |
| **Повторить распознавание** | виден, когда какой-то разговор не удалось превратить в текст |
| **Открыть файл настроек** | `config.json` в Блокноте |
| **Открыть журнал** | папка с журналами |
| **Запускать вместе с Windows** | запускает программу при входе в Windows |
| **Проверить обновления** | спрашивает репозиторий сейчас |
| **Выход** | завершает программу; идущая запись на этом заканчивается и сохраняется |

Когда код на диске изменился — после обновления или после `git pull` руками, — в меню появляется
пункт, который перезапускает программу. Пока идёт запись, он неактивен.

**Панель.** В списке у каждого разговора видны время, программа, о чём он (начало выжимки, а пока
её нет — начало самого разговора), длительность, состояние, есть ли выжимка и сколько ещё хранится
звук. Над списком — поиск по сказанному, период и «Скрыть короче»: галочка сначала стоит, с порогом
30 секунд, так что короткий пробный звонок в списке не виден, пока её не снять. Щелчок по разговору
открывает его страницу:

- текст по репликам, со временем; поиск по нему; «сохранить в файл»;
- проигрыватель: обе стороны, только вы или только собеседники;
- выжимка: «Сделать выжимку» и «сделать заново» для ещё одной попытки;
- «распознать заново…» другой моделью Толмача, пока хранится звук, — текст заменяется, когда готов
  новый;
- «Удалить запись» — звук, текст и выжимка, насовсем.

**Выжимки.** Из коробки выжимку делает Claude Code моделью, указанной в `summary.model`. Что в ней
должно быть и в каком виде, написано в файле, который идёт с программой; `summary.prompt` задаёт
ваш собственный файл вместо него. `summary.command` задаёт вашу собственную команду вместо Claude
Code: вся задача приходит ей на вход — указания, затем текст, — а то, что она напечатает, и есть
выжимка; и то и другое в UTF-8:

```
{
  "summary": {"command": ["python", "C:\\tools\\my_summary.py"]}
}
```

Отмеченные в списке разговоры обрабатываются по очереди; очередь останавливается на первом, с
которым не получилось, и говорит почему.

**Свой сервис распознавания.** Из коробки программа обращается к Толмачу, но это не обязательно
Толмач. `gateway.url` задаёт адрес другого сервера — на этом компьютере или в вашей сети, — и
программа шлёт ему тот же запрос:

- `POST <gateway.url>/v1/audio/transcriptions`, форма с `file` — одна сторона разговора в WAV,
  16 кГц, моно, не длиннее десяти минут, — с `response_format`, равным `verbose_json`, и, если задан
  `gateway.model`, с `model`;
- ответ — JSON с `segments`: фразы, у каждой `start` и `end` в секундах от начала файла и её
  `text`.

Это запрос API распознавания OpenAI, так что подойдёт сервер, который его понимает. Если
`gateway.key_file` указывает на файл, его содержимое уходит в заголовке `Authorization: Bearer`.
Если сервер отвечает на `GET <gateway.url>/v1/models` списком своих моделей, «распознать заново…»
предлагает их. Звук идёт прямо на этот адрес, никогда через прокси, и дальше никуда не
пересылается: сервер, который отвечает перенаправлением, больше ничего не получает.

Перед тем как отправить куски разговора, программа спрашивает `GET <gateway.url>`. Если ответа нет
вовсе, значит, сервера нет: разговор ждёт, а причина записана в `logs\protocallist.log`. Если на
кусок звука пришла ошибка, разговор пробуется три раза и помечается как нераспознанный, с причиной
на его странице. Адрес пишите без `/v1` на конце; адресу `https` нужен сертификат, которому доверяет
Windows. Программа проверялась только с Толмачом — со своим сервером начните с короткого звонка.

```
{
  "gateway": {"url": "http://127.0.0.1:8000", "model": "large"}
}
```

**Из командной строки.** `.venv\Scripts\python -m protocallist --microphones` печатает имена
микрофонов так, как их называет Windows. `--console` запускает один только записывающий сервис в
окне консоли — без значка, без распознавания и без панели — и требует, чтобы в файле настроек были
заданы `recording.enabled` и `recording.microphone`.

## Настройки

`%USERPROFILE%\.protocallist\config.json` (пункт меню «Открыть файл настроек»). Файл читается при
запуске программы; то, что меняется из меню, записывается в него сразу.

| Ключ | По умолчанию | Что делает |
|---|---|---|
| `language` | `"auto"` | язык меню и панели: `"ru"`, `"en"` или `"auto"` — русский, если Windows или её региональный формат русские, иначе английский |
| `recording.enabled` | `false` | записывать разговоры; пункт меню «Записывать разговоры» |
| `recording.microphone` | `""` | микрофон, по которому замечается разговор — его заняла программа, — как его называет Windows; выбирается в меню |
| `recording.speaker` | `""` | устройство воспроизведения, с которого пишется «то, что слышно»; пусто — устройство той же гарнитуры, что и микрофон |
| `recording.ignore` | `["python.exe", "pythonw.exe", "SystemSettings.exe", "rundll32.exe"]` | программы, чьё обращение к микрофону разговором не считается, по имени файла |
| `recording.min_seconds` | `5` | запись короче выбрасывается: программа тронула микрофон, а никто не говорил |
| `recording.linger_seconds` | `5` | сколько микрофон может быть свободен, прежде чем разговор считается оконченным |
| `recording.poll_seconds` | `1` | как часто спрашивать у Windows, кто держит микрофон; от 0.2 до 10 |
| `storage.keep_audio_days` | `30` | сколько дней хранится звук распознанного разговора; 0 — не хранится, меньше нуля — бессрочно |
| `gateway.url` | `""` | адрес вашего собственного сервера распознавания; пусто — Толмач этого компьютера, находится сам |
| `gateway.key_file` | `""` | файл с ключом, с которым обращаются к серверу; пусто — ключ Толмача, а для своего сервера — без ключа |
| `gateway.model` | `""` | модель, которую просят у своего сервера; пусто — модель не называется |
| `summary.model` | `"opus"` | модель, которую просят у Claude Code: псевдоним вроде "opus" или "sonnet" либо полное имя |
| `summary.command` | `[]` | ваша собственная команда, которая делает выжимки, списком — программа, затем её аргументы — вместо Claude Code |
| `summary.prompt` | `""` | файл с вашими указаниями для выжимки; имя без папки ищется рядом с файлом настроек |
| `panel.port` | `0` | порт панели; 0 — программа при первом запуске выбирает порт вашей учётной записи Windows и записывает его сюда |

Настройка с ошибкой заменяется значением по умолчанию, и окно `protocallist.cmd` говорит, какая.
Одна — нет: при ошибке в `storage.keep_audio_days` звук не удаляется вовсе. Файл, который вообще не
JSON, не используется: пока его не исправят, ничего не записывается, а значок говорит, что
настройки не читаются.

## Где что лежит

- В `%USERPROFILE%\.protocallist\` лежат настройки, архив — база `protocallist.db` и папка `calls`
  со звуком каждого разговора и копией его выжимки рядом, — ключ панели (`panel.key`) и журналы
  (`logs\protocallist.log`, `logs\startup.log`). Переменная `PROTOCALLIST_HOME` переносит папку в
  другое место.
- Сказанное в журналы не пишется никогда.
- Чтобы убрать программу: выключите «Запускать вместе с Windows», выберите «Выход», затем удалите
  папку программы и, если архив тоже не нужен, `%USERPROFILE%\.protocallist\`.

## Обновление

Программа сверяет себя с репозиторием при запуске, каждые шесть часов и по пункту «Проверить
обновления». Когда есть версия новее, в меню появляется «Обновить до X.Y.Z»: по щелчку код
обновляется (git, только перемотка вперёд) и программа перезапускается — но не во время записи.
Обновление запускает код из репозитория с вашими правами, поэтому оно ставится только по щелчку.
Копии со своими коммитами обновления не предлагаются; копии с изменёнными файлами предлагаются, но
не ставятся — меню говорит почему.

История версий: [CHANGELOG.md](CHANGELOG.md).

## Разработка

```
.venv\Scripts\python -m pytest -q
```

Тесты ничего не записывают, и ни микрофон, ни Толмач им не нужны. Те, что читают страницу панели,
открывают её в Edge или Chrome без окна и пропускаются, если нет ни того ни другого.
